Each line is the path a message takes from the node serving this page. Direct means ESP-NOW heard it first-hand; multi-hop means the third node relayed it.

Pour

pumps and relays

A pour from here follows the same rules as the joystick: one pump at a time, none in SAFE, none from a low reservoir, none into a full cup. A refused pour shows up in red and in the event log.

Safe state

—

Trip SAFE makes the pump station enter its safe state as if a fault had happened: pumps off, both buzzers on, LED flashing red. Acknowledge clears it once Node 3 (the cup sensor) is reachable. With Node 2 off, the system then runs DEGRADED from this page.

Outputs

buzzers and LED

A buzzer beeps for 1 second. The LED shows red, green, then blue, so a swapped wire is easy to spot. A button is greyed out while its node is LOST.

Range

—

ESP-NOW reaches every node directly on a bench, so this makes Nodes 1 and 3 ignore what they hear first-hand from each other. Their messages then only arrive relayed by Node 2, and the mesh links card on the Live tab shows the multi-hop path. Press it again to put them back in range.

Inputs

live readings

Raw is the sensor's analogRead value. To calibrate, note it dry and at the full mark, then put the two numbers in LEVEL_RAW_DRY / LEVEL_RAW_FULL on Node 1 and CUP_RAW (one raw value per fill mark) on Node 3.
